# 简历项目表述

**施工现场目标识别与三维尺寸测量｜小组全流程负责人**

项目描述：面向施工现场安全评估与几何测量，统筹数据标注、模型训练、深度相机测量及成果汇报，完成目标检测与三维测量实验。

1. 基于 PyTorch 与 YOLOv5 搭建工人、安全帽、反光衣三类目标检测流程，组织图像筛选、标注及训练验证；排查类别编号与标签顺序不一致问题，完成检测结果可视化与实验评估。
2. 基于 RealSense 深度相机对齐 RGB 与深度数据，结合高斯滤波、Canny 边缘检测及概率霍夫变换提取直线，通过端点三维坐标计算实际尺寸；调整边缘检测参数并过滤无效深度线段，结合 SVR 平面拟合开展平整度检测。

## 表述依据与边界

- 项目范围来自实验三与实验四的小组汇报及现存代码。负责人身份采用本人提供的信息。
- 小组实验四汇报记载约 1000 张选取图片、每人标注约 200 张；当前提交目录实际保留 521 张图片，简历未将汇报数量当作可复现数据量。
- 原表述中的“改进 Canny”调整为具体的预处理、参数调优和无效深度过滤；现存代码未显示新的 Canny 算法实现。
- 未找到机械臂控制、手眼标定、路径规划、抓取姿态优化或抓取闭环的实现与实测记录，当前版本不包含这些成果。若另有对应代码，可补充独立的机械臂项目。
- 汇报写 Labelme，操作指引同时介绍 LabelImg，提交的是 YOLO TXT 标签；标注工具名称需本人核实后再加入简历。
